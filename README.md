# OXE Táxi Aéreo — site

Site da **OXE Táxi Aéreo** (Maceió/AL).

## Como abrir o site no seu computador

1. Nesta página, clique no botão verde **Code** e depois em **Download ZIP**.
2. Encontre o arquivo baixado, clique com o botão direito e escolha **Extrair tudo**.
3. Abra a pasta extraída e dê dois cliques no arquivo **index.html**.
   O site abre no seu navegador (Chrome, Edge, Safari...).

> **Importante:** mantenha todos os arquivos e pastas juntos. O `index.html` precisa das
> pastas `css`, `js`, `images` e `fonts` para funcionar.

## Como colocar o site na internet

Envie **todos** os arquivos e pastas para a hospedagem do site, do jeito que estão.
